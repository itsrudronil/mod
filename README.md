# 2X Client (Minecraft 26.1)
Fabric client mod for Minecraft 26.1 / 26.1.1 / 26.1.2 by Its Rudronil. Needs Java 25, Fabric Loader 0.19.2+ and Fabric API.

Right Shift = menu (Edit HUD button inside). Hold C = zoom.
Waypoints: /2x wp add <name>, /2x wp remove <name>, /2x wp list

Build on GitHub: push the repo, open the Actions tab, download the `2x-client-26.1` artifact.
