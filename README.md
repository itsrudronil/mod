# 2X Client
Fabric client mod for Minecraft 1.21.11 by Its Rudronil.

1. Install JDK 21 and open in IntelliJ IDEA.
2. Add the Gradle wrapper (`gradle wrapper`, or copy gradlew/gradle/ from the Fabric template at https://fabricmc.net/develop/template).
3. `./gradlew build` -> jar in `build/libs/`.
4. `./gradlew runClient` to test.
